# Widget height and width in jEasyUI

Widget groups with undefined height size to their content when they have one column
or do not need a Masonry layout (for example, a two-column-wide group containing a
single full-width input). Explicit heights, including `max`, retain their fill behavior.

Displays clip overflowing content normally and reveal it without scrollbars on hover
or keyboard focus. Widget group wrappers allow the revealed content to extend beyond
the group without changing its layout. On devices without hover, Displays remain scrollable.
